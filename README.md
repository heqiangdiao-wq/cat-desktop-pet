# 猫咪桌面萌宠 🐱

一只住在桌面上的小猫咪。它会呼吸、会眨眼、会甩尾巴，还会——

- 💨 **放屁**：蹲一下，眯起眼睛，屁股后面冒出一团绿色的云
- 😹 **大笑**：眼睛变成两条弧线，张大嘴巴，整个身子蹦蹦跳跳

## 快速开始

### 方式一：直接安装（推荐）

到 [Releases](../../releases) 页面下载 `猫咪萌宠 Setup 1.0.0.exe`，双击安装即可。

也可以下载 `猫咪萌宠 1.0.0.exe`（免安装单文件绿色版），双击直接运行，不写注册表。

### 方式二：从源码运行

```bash
npm install
npm start
```

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 左键点猫咪 | 随机触发「放屁」或「大笑」 |
| 按住左键拖动 | 把猫咪拖到屏幕任意位置 |
| 右键点猫咪 | 打开菜单：放屁 / 大笑 / 置顶 / 退出 |

猫咪窗口是透明、无边框、始终置顶的，**空白处的鼠标点击会穿透到下面的窗口**，不会挡住你干活。

## 技术栈

- Electron（透明 + 无边框 + ALWAYS_ON_TOP 窗口）
- 纯 SVG + CSS 动画绘制猫咪，不含任何位图素材，任意缩放都清晰
- 窗口尺寸小、内存占用低
